# 평가 계획 합의·범위 결정 기록

2026-10-26. Codex와 Claude CLI가 7회 토론했고, 7라운드에서 새 구축·실행 상세안 본문을 읽고 명시적으로 승인했다. 이 기록은 두 AI 에이전트의 설계 검토이며 사용자·교수의 실험 결과 승인을 뜻하지 않는다.

## 현재 결정과 읽을 문서

사용자가 최종적으로 **기존 결과를 제외하고 S1~S4 모두 새로 평가**하기로 결정했다. 추가 축소 요청이 없으므로 구현 작업은 합의안의 전체 기준인 **F-repeated**를 따른다. 범위 선택을 다시 묻거나 과거 20시간 가정에 맞춰 S1-only로 줄이지 않는다.

1. [구현 시작 프롬프트](../fresh-evaluation-implementation-prompt-2026-10-26.md): 확정된 범위와 코딩 에이전트에게 전달할 작업 지시.
2. [구축 상세안](../fresh-evaluation-build-plan-2026-10-26.md): 파일별 B01~B11, 증거·판정·검증·완료 조건.
3. [실행 상세안](../fresh-evaluation-run-plan-2026-10-26.md): 비교군·run 목록·SOP·freeze·시간·실패 규칙.
4. [연구 설계](../consensus-research-plan-2026-10-26.md): 전체 연구 질문·통제·지표·주장 제한.

구축·실행 상세안은 7라운드 승인본을 그대로 보존했다. 그 문서의 ‘범위 미선택’ 표현은 이후 사용자 결정으로 해소됐으며 실제 일정·비용·사람 참여·pilot 값은 별개다. 이번 작업은 프롬프트·문서 정리 단계이고 구현·live 실험·클라우드 비용 집행은 수행하지 않았다.

## 토론으로 정리한 결정

| 쟁점 | 합의 |
|---|---|
| 연구 완결성과 신뢰도 보장 | 99%·299회 등은 주장 확장 조건이며 모든 졸업 논문의 필수값이 아님 |
| S1 기여 | OpenStack 물리 정보를 활용하는 K8s 재배치. 현 topology에서 위치 정보 자체의 효과와 재배치 효과를 혼동하지 않음 |
| S2 대조 | P의 순차 무제어 창은 독립 M 대조가 아님. 새 P/M 비교와 H 전체 업로드 지속을 확보 |
| S3 시간·통제 | 기존 NotReady 이름의 필드는 진단완료 시각. 실제 관측을 분리하고 timer가 다른 군을 조치 제거 비교로 쓰지 않음 |
| S4 기여 | MHC/CAPI/CAPO의 기존 복구와 자체 통합 workflow를 구별 |
| 과거 자료 | 삭제하지 않고 개발 이력으로 보존. 새 primary·비교·표본 수에 혼입하지 않음 |
| 강건성 판정 | 예외 중단은 정상 보류가 아님. trial_valid와 recovered, 안전·가용성·실행 결과를 분리 |
| 구현 | 기존 raw 보존 + 독립 adapter. 필요한 계측만 추가하고 기존 S1 no-action을 재사용 |
| freeze | 시나리오별 freeze 허용, S1 모든 main은 동일 freeze, 정책 hash 불변. 도구 수정은 diff·영향 분석·새 cohort |
| 범위·시간 | 전체 반복 비교와 대조 시연 축소안을 모두 유효하게 설계. 이후 사용자가 전체 새 평가를 선택 |

F-repeated는 본시험29 run, 준비/pilot8 run, 별도 개발 smoke로 구성된다. 테스트베드 추정은1953.6분(32시간33.6분)이며, 구현·분석·집필 시간은 별도다. 사람과 transient는 추가 선택 항목이다. 이 추정은 실제 모드의 pilot으로 갱신해야 하며 실행 완료나 비용 보장이 아니다.

## 산출물 정리와 보존

사용자의 정리 요청에 따라 중간 초안·독립 비교·초기 실행안·라운드별 prompt/JSON·인증 실패 로그·CLI session ID를 현행 문서 디렉터리에서 제거했다. 삭제 전 원문을 로컬 아카이브에 복사하고 SHA-256을 검증했다.

로컬 보존 위치: `artifacts/planning-archive/2026-10-26-evaluation-consensus/`. 이 경로는 저장소의 기존 `artifacts/` 제외 규칙에 따라 Git에 포함하지 않는다. `archive.sha256.json`에 보존 파일 목록과 hash가 있다. 커밋에는 현재 사용 문서와 최종 승인 원문·hash만 포함한다. 기존 실험 raw와 이미 추적 중인 과거 검증 문서는 변경하지 않았다.

연구 설계 문서는 정리 과정에서 도입부의 중간 자료 링크를 현행 문서 링크로 바꾸고 사용자 결정을 명시했다. 연구 설계 본문은 변경하지 않았으며 승인 당시 원본도 로컬 아카이브에 보존했다. 구축·실행 상세안은 파일 전체가 승인본과 동일하다.

최종 검토의 비차단 권고: 세션 내 pilot→main은 source를 바꾸지 않고 사전 등록한 parameter를 확정하는 전환이며 운영50분에 포함한다. 정책과 계측이 같은 파일에 있으면 계측 수정도 policy hash 규칙을 적용한다. 필요한 helper 분리는 최초 main 전에 수행하고 이후 즉석 hash 예외는 허용하지 않는다.
